## 分镜与旁白

### 01 / Hook · 0.0–11.0秒

这周刚刚上线的三维分割大模型基座nnFoundation，到底好不好用？

我们拿一个真实案例跑一下。这次，是小鼠的肿瘤 CT。

### 02 / Foundation · 11.0–23.0秒

它用210万份三维影像预训练，给下游任务提供一个起点。

我们选 CNN 版本：三维进、三维出，接上分割解码器，再整体微调。

### 03 / Data · 23.0–33.5秒

数据来自公开的 TumSeg。第一轮，两只训练，五只测试。

按动物和同次采集组隔离，用专家融合标注作为参考。

### 04 / Design · 33.5–52.7秒

两轮都从官方预训练权重重新开始，整网训练30轮，每轮50步。

批量为2，三维图块边长128，用最终检查点，不按测试成绩挑模型。

在4090笔记本显卡上走 CUDA，首轮训练用了大约18分钟。

### 05 / Baseline · 52.7–66.9秒

结果，五例平均 Dice 只有57.5%。基座大，并不意味着小样本就稳。

最差的 M07，目标切片看起来很准，整只动物的三维 Dice 却只有31%。

### 06 / Diagnosis · 66.9–79.9秒

把视野拉到全身，问题出现了：远处多分出了很多本不该有的区域。

所以，不能只挑一张好看的切片。要看完整体积，也要区分多分和漏分。

### 07 / Geometry · 79.9–95.5秒

我们还发现，数据里的两套空间信息冲突。体素间距，一处是0.21毫米，一处是1毫米。

先按论文和原始 qform 统一实验副本，不改图像像素，才能正确计算距离和体积。

### 08 / FourShot · 95.5–107.7秒

第二轮，把原来七只重新分成四训三测，训练预算保持不变。

这三只之前已经看过，所以只能叫开发性复测，不能算新的独立测试。

### 09 / Comparison · 107.7–119.6秒

公平比较，要看同样的三只。两例训练的平均 Dice 是61.1%。

增加到四例后，升到70.1%。但远端误分，仍然存在。

### 10 / Guard · 119.6–139.2秒

接着，只用四例训练数据，学习肿瘤在身体长轴上的相对位置。

加5毫米余量，再过滤极小的区域，保留完整连通块，也允许多个肿瘤。

应用时只看 CT、预测和固定规则，不读取这三例的参考标注。

### 11 / Results · 139.2–159.1秒

清理后，三例平均 Dice 达到86.2%，IoU 是75.8%。

距离参考肿瘤10毫米以外的误分归零，没有额外删掉原本分对的体素。

但局部漏分还在。这套位置规则，也可能误删异位或很小的肿瘤。

### 12 / Lessons · 159.1–174.8秒

这次学到的是：先核对数据和划分，再看全体积，最后用场景知识处理具体错误。

它是有用的微调起点，但这次没有从零训练对照，还不能证明预训练的收益或通用泛化。

### 13 / Github · 174.8–188.4秒

小鼠 CT 的复现代码、参数和结果，已经上传到屏幕上的 GitHub 地址。

我是思语视觉，一起把论文跑成看得见的结果。
