# 输入图像与人工参考

图像为作者提供的H&E肾脏组织截图，1024×791，未画框；原始切片出处、放大倍数和批次未能核对。不使用已经画过模型框的图作为输入。

gt-manual.json包含作者人工标注的37个肾小管框，以1164×900为评价空间，x/y为中心，width/height为框大小。边缘截断肾小管没有标注；右侧一个较大的框为人工标注的实际选择，评价时原样保留。

归一化预测和参考映射到同一1164×900空间评分。用于QuPath的GeoJSON另外换算回干净JPEG的1024×791像素坐标，原点左上角，单位像素。这些矩形表示检测框，不是精细分割。

图像经作者明确授权随此次评测公开；原始来源尚未核实，不为它附加推测的第三方许可。母仓库MIT许可适用于自有代码，不自动替代第三方图像权利。
